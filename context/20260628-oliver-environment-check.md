## 3. 실행 가능한 방법 (Git 없음)

### 3.1 파일 시스템 기반 작업 (즉시 적용)
- 원본 경로: `company/`, `decision/`, `research/`, `design/`
- 백업 경로: `archive/YYYYMMDD_[작업자]_[파일명].md`
- 보고 경로: `context/YYYYMMDD_[작업자]_[작업명].md`
- 변경 이력: 각 문서 하단에 `## 변경 이력` 섹션 의무화

### 3.2 검증 방법 (Gitless)
1. 원본 파일 메타데이터 확인 (작성자, 날짜, 버전)
2. 원본 vs archive 비교 → diff 내용을 보고서에 포함
3. 팀원 cross-review (인접 담당자가 서로 검토)
4. 최종 리더 검토

### 3.3 Oliver의 새로운 운영 루틴
- 매일 오전 9시: `context/YYYYMMDD-oliver-daily.md` 생성
  - 오늘의 작업 목록 1~3개
  - 각 작업의 원본 경로·예상 완료 시각
  - 리스크와 필요한 지원 항목
- 매 작업 완료 후:
  - 원본 저장
  - archive 저장
  - context 보고서 작성
  - June님께 Slack DM으로 경로만 전달 (내용은 문서 참조)
