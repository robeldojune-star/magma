## 2. Git 없는 작업 방식 (운영 규칙)

### 원칙
- **원본 파일 직접 수정** — scratch 임시 파일 생성 금지
- **버전은 파일 상단 메타데이터**로 관리 (날짜, 작성자, 버전, 변경내용)
- **백업은 로컬 압축** — `/home/june/magma/magma-backup-YYYYMMDD.tar.gz`
- **변경 이력은 `archive/` 폴더**에 날짜별로 보관

### 파일 저장 규칙
1. 원본을 덮어쓰지 않고 새 버전 생성:
   - 예: `company/05-네이밍-브랜드보이스.md` → `company/05-네이밍-브랜드보이스_v20260628.md`
2. 또는 `archive/`에 이전 버전 이동 후 원본 갱신
3. 파일 상단에 메타데이터 기록:
   ```markdown
   # 문서 제목

   - 작성자: Noah / 카피
   - 날짜: 2026-06-28
   - 버전: v1.0
   - 변경내용: 보이스 가이드 초안 작성
   ```

### 백업 명령
```bash
# 작업 전/후 매번 실행
tar -czf /home/june/magma-backup-$(date +%Y%m%d-%H%M).tar.gz /home/june/magma
```
