# 규칙 확인 지시

## 목적
Oliver가 전파한 규칙을 팀원 각자가 이해했는지 확인한다.

## 확인 방법
각 팀원은 반드시 **올리버(Oliver)**에게 아래 중 하나로 회신한다.
- 이해함
- 이해 못함

## 대상 팀원과 Owner 매핑
- Ethan: `company/01-brand-deck.md`
- Mia: `company/04-디자인시스템.md`
- Noah: `company/05-브랜드보이스.md`
- Ada: `company/08-가격포지셔닝확정안.md`

## 규칙 핵심 5가지 (Oliver가 전파한 내용)
1. 원본 경로(`company/`, `research/`, `decision/`)에 저장
2. 파일명 형식: `##-이름.md`
3. 파일 상단 메타데이터 의무화
4. 완료 보고 형식: 결론 → 근거 → 변경 파일 경로
5.Oliver 검토: 24시간 내 검토
