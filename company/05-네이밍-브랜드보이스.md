## 2. 핵심 규칙

- 짧은 문장을 주로 사용.
- 복잡한 설명은 단순하게 풀어 낸다.
- 전문 용어는 반드시 필요할 때만 사용.
- 신조어·유행어 사용 금지.
- 광고성 표현 대신 실제 사용 경험에 가까운 표현 사용.

## 3. 항목별 톤앤매너

| 항목 | 톤앤매너 |
|------|-----------|
| 제품 설명 | 불필요한 수식어를 줄이고 소재·핏·사용감 중심으로 작성 |

## 4. 채널별 사용 가이드

### 4-1. 명함·패키지
- 브랜드명: M:AGMA
- 태그라인: SOLID TRUST
- 슬로건: ESSENCE IN MOTION
- 형식: 텍스트 위주, 시각 요소는 최소화

### 4-2. 웹사이트·쇼핑몰
- 불필요한 단정부사("최고", "완벽", "모두", "확실히") 사용 금지
- 제품 소개는 소재·사이즈·핏·관리법 포함
- CTA는 기능 중심 문구로 대체

### 4-3. 이메일·뉴스레터
- 제목은 10단어 이내
- 문장은 2~3문장 단위로 끊어 읽기 편하게 배치
- 수신자 이름으로 시작, 불필요한 인사 장문 생략

### 4-4. SNS
- 1회 3문장 이내
- 질문형 종결 대신 사실 전달형 종결 사용
- 사진 설명은 최소화, 이미지가 설명하도록 함
