## 4. 반영 내용 상세

규칙 v1.1에 반영되는 내용은 다음과 같다.

- 카드 작성 5문항 의무화: 필수 5문항을 규칙 2.1에 추가하고, 미작성 시 진행 불가로 명시한다.
- 상태 전이 순서 강제: IDEA → RESEARCH → DISCUSSION → DESIGN → BUILD → REVIEW → READY → COMPLETED 순서 강제, 건너뛰기 금지.
- 파일 Owner 매핑: 규칙 2.4에 Owner 매핑 기준을 추가하고, 변경 책임을 단일화한다. 상세 참조표는 `company/02-work-guide.md`로 분리해 규칙 문서는 참조만 유지한다.
- 메타데이터 의무: 최상단 6항목과 변경 이력(날짜·변경자·내용) 작성을 의무화한다.
- COMPLETED 3조건: 원본 경로 존재, 메타데이터 정상, 검증 완료를 모두 충족해야 COMPLETED로 전환한다.
- 문제 보고 의무: 충돌·권한 오류·파일 손상 발견 시 자체 복구 금지, Oliver 보고 후 대기.
- Slack 채널 ID 명시: 전파 채널로 `C0B8U8VK70C`를 규칙 본문에 명시하고, 채널 변경 시 규칙 업데이트를 의무화한다.
- 메타데이터 검증 기준 표: 누락 시 처리 단계와 예외 기준을 표로 정리한다.
- 소규모 수정 기준: 오타·문구 보정 등 소규모 수정은 Owner 직접 적용을 허용하고, 기준을 명시한다.
- 의사결정 경로 별도 카드: 피드백 반영 여부는 별도 칸반 카드로 팀 검증 후 결정한다.
- 원본 경로 확인, 타 경로 처리 기준: 원본 경로 확인 절차와 예외 발생 시 Oliver 보고를 추가한다.
