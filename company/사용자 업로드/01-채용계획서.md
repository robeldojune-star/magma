> ⚠️ 스킬 식별자는 skills.sh 허브에서 검증한 값입니다. 허브 사정으로 설치가 안 되면 skills.sh에서 스킬 이름으로 다시 검색해 최신 식별자를 쓰면 됩니다. 설치 시 헤르메스가 보안 스캔을 수행하며, 커뮤니티 스킬이므로 `hermes skills inspect <식별자>`로 한 번 들여다보고 설치하는 습관을 권합니다.

## §8. 채용 집행 2부 — 슬랙 출근 (Oliver가 일괄 진행, 대표는 토큰만)

다섯 명 모두 슬랙으로 출근시킵니다. 역할 분담: **앱 생성·설정·게이트웨이 기동은 Oliver(자동)**, **슬랙 보안상 사람만 할 수 있는 일(토큰 발급)만 대표(수동)** 입니다.

### 8-1. [Oliver] 게이트웨이 현황 확인

```bash
hermes gateway list
```

현재 활성 게이트웨이를 확인합니다. 신규 직원 5명(ada·ethan·noah·mia·sam)은 아직 게이트웨이가 **비활성(미연결)** 상태여야 정상입니다. 이 상태를 대표에게 한 줄 보고하고 다음으로 갑니다.

### 8-2. [대표] App Configuration Token 발급 → 채팅창에 붙여넣기

1. `https://api.slack.com/reference/manifests#config-tokens` 에서 **Generate Token** 을 눌러 워크스페이스를 선택합니다.
2. 발급된 **Access Token** 을 Oliver와의 채팅창에 그대로 붙여넣습니다.

> ⚠️ 이 토큰은 **12시간 만료 + 갱신(refresh) 시 회전**되는 일회성 작업 토큰입니다. 그래서 `.env` 같은 파일에 저장하지 않고 **채팅으로 전달해 이번 세션에서만** 씁니다. Oliver는 작업용 환경변수(`SLACK_CONFIG_ACCESS_TOKEN`)로만 들고 앱 생성에 쓰며, **§8 작업이 끝나면 슬랙 토큰 페이지에서 이 토큰을 삭제(또는 회전)하라고 대표에게 제언**합니다.

### 8-3. [Oliver] 매니페스트 생성 + 직원별 치환

직원마다 기본 매니페스트를 만들고, **개인별로 다른 3개 필드만** 바꿉니다.

```bash
# 직원마다 기본 매니페스트 생성
hermes -p <id> slack manifest --write --name "<아래 표의 앱 이름>"
# → ~/.hermes/profiles/<id>/slack-manifest.json 생성
```

매니페스트는 직원 간 99% 동일하고, 다른 곳은 이 3개 필드뿐입니다. 표대로 치환(replace)합니다.

| 직원  | `display_information.name` | `display_information.description`                                        | `features.bot_user.display_name` |
| ----- | -------------------------- | ------------------------------------------------------------------------ | -------------------------------- |
| ada   | MAGMA Ada                  | MAGMA 데이터분석가 — 타겟 세그먼트·가격 포지셔닝을 숫자로 분석합니다.    | Ada                              |
| ethan | MAGMA Ethan                | MAGMA 기획자 — 브랜드 전략·사업영역·비즈니스 모델을 설계합니다.          | Ethan                            |
| noah  | MAGMA Noah                 | MAGMA 작가 — 네이밍·슬로건·브랜드 스토리·톤앤매너를 씁니다.              | Noah                             |
| mia   | MAGMA Mia                  | MAGMA 디자이너 — 로고·VI 컨셉·무드보드·덱 비주얼을 만듭니다.             | Mia                              |
| sam   | MAGMA Sam                  | MAGMA 개발자 — 온라인 채널·데이터 파이프라인을 만듭니다(입사 예정).      | Sam                              |

치환 후 최소 봇 스코프 14종이 들어 있는지 확인합니다(없으면 추가): `app_mentions:read` `channels:history` `channels:read` `chat:write` `commands` `files:read` `files:write` `groups:history` `groups:read` `im:history` `im:read` `im:write` `mpim:read` `users:read`.

> 💡 **지름길**: 수강생 전용관 프로젝트 파일 `assets/manifest/<id>.json` 은 위 치환·스코프 보정을 **이미 마친 완성본**입니다. 내려받아 그대로 8-4에 써도 됩니다(앱 아이콘은 `assets/app-icons/<id>.png`).

### 8-4. [Oliver] 슬랙 앱 5개 자동 생성

```bash
curl -sS https://slack.com/api/apps.manifest.create \
  --data-urlencode "token=$SLACK_CONFIG_ACCESS_TOKEN" \
  --data-urlencode "manifest=$(cat ~/.hermes/profiles/<id>/slack-manifest.json)"
```

직원 5명에 대해 반복합니다. 응답의 `"ok": true` 와 `app_id` 를 직원별로 기록해 둡니다.

### 8-5. [대표] 토큰 발급 → oliver의 .env 채우기 → "넣었어"

앱 5개가 생기면, 사람만 할 수 있는 일이 시작됩니다. 앱마다:

1. 앱 설정에서 **Install App** 으로 워크스페이스에 설치합니다.
2. **OAuth & Permissions** 에서 **Bot User OAuth Token** (`xoxb-…`)을 복사합니다.
3. **Basic Information → App-Level Tokens → Generate** 로 스코프 `connections:write` 의 **App-Level Token** (`xapp-…`)을 만듭니다(소켓 모드용).

그리고 공통 2개 — 본인 슬랙 **member id** (`U…`)와 봇들이 활동할 **채널 id** (`C…`)를 확인합니다.

모은 값(직원별 토큰 5쌍 + 공통 2개)을 **`~/.hermes/profiles/oliver/.env`** 에 채웁니다. 빈 키만 있는 템플릿이 수강생 전용관 `.hermes/profiles/oliver/.env` 에 배포되어 있으니, 그 파일을 받아 채워 넣으면 됩니다.

다 채웠으면 채팅창에 **"넣었어"** 라고 입력합니다. **Oliver는 이 신호가 올 때까지 대기**합니다.

> ⚠️ 토큰 값에 접두사를 두 번 붙이지 않도록 주의합니다(`xoxb-xoxb-…` 는 인증 루프의 흔한 원인). 템플릿의 키 값은 비어 있으니 발급받은 토큰 전체를 그대로 붙여넣으면 됩니다.

### 8-6. [Oliver, "넣었어" 수신 후] 토큰 배분

`~/.hermes/profiles/oliver/.env` 를 읽어 직원별 프로필에 배분합니다. 직원마다:

```bash
# ~/.hermes/profiles/<id>/.env  (chmod 600)
SLACK_BOT_TOKEN=<해당 직원의 xoxb- 토큰>
SLACK_APP_TOKEN=<해당 직원의 xapp- 토큰>
SLACK_ALLOWED_USERS=<공통 member id>
SLACK_HOME_CHANNEL=<공통 채널 id>
```

배분 전 형식을 검증합니다(`xoxb-`/`xapp-` 접두사, U/C 시작). 배분이 끝나면 **oliver의 .env에서 직원 토큰 줄은 비워 두라고 제언**합니다 — 정본은 각 직원의 .env 하나면 충분합니다.

### 8-7. [Oliver] 게이트웨이 기동

```bash
hermes -p ada gateway run
hermes -p ethan gateway run
hermes -p noah gateway run
hermes -p mia gateway run
hermes -p sam gateway run
```

### 8-8. [Oliver] 최종 확인 + 대표 보고

```bash
hermes gateway list
```

5명 모두 활성으로 보이면, 대표에게 최종 보고합니다 — ① 채용 5명(프로필·페르소나·도구) ② 슬랙 앱 5개 생성·연결 ③ 게이트웨이 5개 가동 상태 ④ 남은 제언(App Configuration Token 삭제·회전, oliver .env의 직원 토큰 줄 비우기).

## §9. 채용 완료 확인 (대표)

```bash
hermes profile list   # oliver·ada·ethan·noah·mia·sam 6명이 보이면 채용 완료
hermes gateway list   # 5명 게이트웨이 활성 확인
```

각 직원에게 한 줄씩 자기소개를 시켜(예: `ada -z "한 문장 자기소개"`) 페르소나가 카드대로 들어갔는지 확인하고, 슬랙 채널에서 직원 봇 하나를 멘션해 응답을 확인합니다.
