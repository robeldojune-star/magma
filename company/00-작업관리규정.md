# MAGMA 작업관리규정 v1.0
_ver 1.0 / 2026-06-28_

## 1. 원칙
- 모든 작업은 파일 단위로 관리한다.
- 동일 문서를 두 명 이상이 동시에 수정하지 않는다.
- 변경은 게시판 카드와 Slack 공지로 팀에 알린다.

## 2. 등록과 소유권
- 파일 생성 전, 작업 게시판에 카드를 생성한다.
- 주요 회사 문서는 담당자를 명시한다. 담당자는 변경을 주도한다.
- 담당자가 변경할 때는 사전에 동일 문서를 다루는 팀원에게 알린다.

## 3. 수정과 동시성
- 문서 수정은 한 명이 한 번에 하나의 파일을 대상으로 진행한다.
- 누군가 수정 중임을 알리기 위해, 작업 시작 전 해당 카드에 상태를 `진행 중`으로 바꾼다.
- 수정이 끝나면 `완료`로 전환한다.
- 진행 중인 문서를 다른 사람이 열람해야 할 경우, 담당자에게 먼저 확인한다.

## 4. 서버 변경 공유 방법
- 회사 문서가 바뀌면 다음 두 가지를 함께 진행한다.
  1) 작업 게시판 카드를 업데이트한다.
  2) Slack 공지 채널을 통해 변경 내용을 공유한다.
- 개별 팀원 DM은 Slack 공지 채널 제한으로 이벤트 공지용으로만 사용한다.

## 5. 예외와 질문
